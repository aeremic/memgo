# Memgo

Memgo is a lightweight, Redis-like in-memory database written in Go, currently in development. It supports key-value storage with native JSON support, ideal for quick prototyping, development caching, or lightweight real-time applications.

---

## Features

- In-memory key-value store
- JSON-based data storage
- TCP protocol
- Fast and lightweight
- Written in pure Go

---

## Usage

- To run memgo node <code>./memgo_node host_url port</code>
- If **host_url** and **port** are not provided, default ones will be used
- To run memgo orchestrator <code>./memgo_orchestrator path_to_config</code>
